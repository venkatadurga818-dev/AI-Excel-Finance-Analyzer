# AI + Excel Finance Analyzer

AI-assisted finance analysis project that combines Microsoft Excel and AI to help organize financial transactions, analyze cash flow, detect anomalies and produce structured business insights.

## 🎯 Project Objective

Finance workflows often consist of performing repetitive tasks such as classifying transactions, reconciling, analyzing expenses and preparing monthly reports.

This project showcases how we can combine Excel and AI to help structure these workflows in a way that they are more organized, analytical and efficient while preserving human judgement at the core of financial decision making.

## 🔎 What This Project Does

Organizes financial transaction data
Separates income and expenses
Calculates total income and expenses
Calculates net cash flow
Calculates savings rate
Summarizes expenses by category
Helps identify unusual or potentially duplicate transactions
Uses AI prompts to generate structured financial insights
Converts raw transaction data into a concise management summary

## 🧠 AI-Assisted Analysis

AI is leveraged as a productivity and analytical assistant rather than as a replacement for financial judgement.

Some example use cases include:

Identifying potential anomalies
Reviewing spending patterns
Structuring financial observations
Explaining trends in transaction data
Generating management summaries
Helping formulate follow up questions

AI-based observations are sanity checked against the underlying spreadsheet before being treated as conclusion.

## 💡 Example AI Prompt

```text
You are a finance analyst.

Review the transaction data and:

1. Separate income and expenses.
2. Identify the three largest expense categories.
3. Calculate the savings rate from the provided totals.
4. Flag unusual or potentially duplicate transactions.
5. Provide three practical observations.

Use only information available in the dataset.
Do not invent missing data.
Clearly distinguish facts from recommendations.
```
